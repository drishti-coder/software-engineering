add a simple motivational quote.

Your final my_intro.c can look like this:

#include <stdio.h>

int main()
{
        printf("Believe in yourself and keep learning.\n");

    return 0;
}

Compile:

gcc my_intro.c -o my_intro

Run:

.\my_intro

You should get:

Believe in yourself and keep learning.

Push it to GitHub

First, make sure you are inside your GitHub repository folder in the VS Code terminal.

Check the files:

dir

Then check Git:

git status

Add the C file:

git add my_intro.c

Make a commit:

git commit -m "Added my intro C program"

Then push:

git push

If your repository is already connected to GitHub, this should upload the file.

Very simple meaning of Git commands
git add my_intro.c

Means: I want to upload this file.

git commit -m "Added my intro C program"

Means: Save this change in Git.

git push
