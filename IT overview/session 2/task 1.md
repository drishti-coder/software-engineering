steps for making a folder through terminal of vs code



* Step 1: Open VS Code
* Step 2: Open the terminal

  * At the top of VS Code, click:
  * Terminal → New Terminal
* Step 3: Create the folder

  * Type:
  * mkdir my-fav-apps
* Step 4: Go inside the folder

  * Type:
  * cd my-fav-apps
* Step 5: Open this folder in VS Code

  * Type:
  * code .
