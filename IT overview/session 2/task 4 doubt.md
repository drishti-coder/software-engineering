**Create and run hello.js**



* Step 1: Go to the Instagram folder

  * Your terminal should currently be inside:
  * my-fav-apps
  * Type:
  * cd instagram-clone
  * Press Enter.
* Step 2: Create hello.js

  * Type:
  * New-Item hello.js
  * Press Enter.
  * You have now created:
  * hello.js
* Step 3: Open hello.js

  * In the VS Code Explorer, expand:
  * instagram-clone
* Click:

  * hello.js
  * Now type this exactly:
  * console.log('Hello from Instagram Clone!');
* Save the file:

  * Ctrl + S
* Step 4: Run your JavaScript



* inside:

  * instagram-clone
  * You can check using:
  * pwd
* Then run:

  * node hello.js
  * Press Enter.
* You should see:

  * Hello from Instagram Clone!
