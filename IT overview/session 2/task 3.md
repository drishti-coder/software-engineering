**Install VS Code Extensions**



Extension 1: Prettier

* Step 1

  * Look at the left side of VS Code.
  * Click the Extensions icon.
* Step 2

  * Search:
  * Prettier - Code formatter
  * Find the extension from Prettier and click:
  * Install
* What does Prettier do?

&#x20;     Prettier automatically formats my code to make it clean, consistent, and easier to read.



Extension 2: Live Server



* Search for:

  * Live Server
  * Find the popular Live Server extension and click:
  * Install
* What does Live Server do?

  * Live Server lets me open my website in a browser and automatically refresh it when I make changes.
