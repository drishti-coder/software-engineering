**IPv4 vs IPv6**



**IPv4**



**IPv4 uses 32 bits and is normally written as four numbers separated by dots.**



**Example:**



**192.168.1.1**



**IPv6**



**IPv6 uses 128 bits and is normally written using eight groups of hexadecimal characters separated by colons.**



**Example:**



**2001:0db8:85a3:0000:0000:8a2e:0370:7334**



**Comparison**



**Feature	                                             IPv4                                                                          IPv6**



**Address size	                                    32-bit                                                                        128-bit**

**Format	                                         Numbers separated by .	                                               Hexadecimal groups separated by :**

**Example	                                            192.168.1.1	                                                     2001:0db8:85a3:0000:0000:8a2e:0370:7334**

**Number of addresses	                            Much smaller	                                                     Extremely large**
